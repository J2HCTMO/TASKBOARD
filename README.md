# منصة رحلة تحوّل لإدارة المشاريع والمهام

منصة أونلاين لفريقك المكوّن من 4 أعضاء، مع تحديثات لحظية (Realtime) — أي تعديل يظهر تلقائيًا عند بقية الأعضاء بدون تحديث الصفحة.

---

## الخطوة 1 — إنشاء حساب Supabase (قاعدة البيانات) — 5 دقائق

1. اذهبي إلى https://supabase.com واضغطي **Start your project**، وسجّلي دخول بحسابك على Google أو بريدك الإلكتروني (مجاني، بدون بطاقة ائتمان).
2. اضغطي **New project**:
   - اختاري اسمًا للمشروع، مثل `tahawwul-tasks`
   - اختاري كلمة مرور لقاعدة البيانات واحفظيها في مكان آمن (لن تحتاجيها في الكود لكن قد تحتاجينها لاحقًا)
   - اختاري الإقليم الأقرب لك (مثلاً Frankfurt أو أقرب منطقة متاحة)
   - اضغطي **Create new project** وانتظري دقيقة أو دقيقتين حتى يجهز.

## الخطوة 2 — إنشاء الجداول

1. من القائمة الجانبية داخل مشروع Supabase، اذهبي إلى **SQL Editor**.
2. اضغطي **New query**.
3. افتحي ملف `supabase-schema.sql` المرفق مع هذا المشروع، انسخي محتواه بالكامل، والصقيه في المحرر.
4. اضغطي **Run** (أو Ctrl+Enter). سترين رسالة نجاح، وستُنشأ 3 جداول (members, projects, tasks) مع الأعضاء الأربعة جاهزين مسبقًا.

## الخطوة 3 — الحصول على مفاتيح الاتصال

1. من القائمة الجانبية، اذهبي إلى **Project Settings** (⚙️) ثم **API**.
2. ستجدين قيمتين تحتاجينهما:
   - **Project URL** (يشبه `https://xxxxxxxxxxxx.supabase.co`)
   - **anon public key** (نص طويل تحت "Project API keys")
3. احتفظي بهما — ستحتاجينهما في الخطوة القادمة.

## الخطوة 4 — رفع المشروع على GitHub

1. أنشئي حسابًا مجانيًا على https://github.com إن لم يكن لديك.
2. أنشئي مستودعًا (Repository) جديدًا فارغًا، مثلاً باسم `tahawwul-tasks`.
3. ارفعي كل ملفات هذا المشروع إليه (يمكنك سحب وإفلات الملفات مباشرة من واجهة GitHub في المتصفح إذا لم تكوني معتادة على Git، عبر زر **uploading an existing file** في صفحة المستودع الفارغ).

## الخطوة 5 — النشر على Vercel (مجانًا) — 5 دقائق

1. اذهبي إلى https://vercel.com وسجّلي دخول بحساب GitHub الخاص بك مباشرة.
2. اضغطي **Add New... > Project**.
3. اختاري مستودع `tahawwul-tasks` الذي رفعتِه.
4. في صفحة الإعدادات قبل النشر، افتحي قسم **Environment Variables** وأضيفي:
   - `VITE_SUPABASE_URL` = القيمة التي نسختِها من Supabase
   - `VITE_SUPABASE_ANON_KEY` = القيمة التي نسختِها من Supabase
5. اضغطي **Deploy** وانتظري دقيقة تقريبًا.
6. بعد الانتهاء، ستحصلين على رابط مثل `tahawwul-tasks.vercel.app` — هذا هو رابط موقعك الأونلاين، شاركيه مع الأعضاء الأربعة.

---

## التجربة محليًا قبل النشر (اختياري)

إذا أردتِ تجربة المشروع على جهازك أولًا قبل رفعه:

```bash
npm install
cp .env.example .env
# افتحي ملف .env وضعي فيه قيم Supabase الحقيقية
npm run dev
```

## ملاحظات مهمة

- **لا يوجد تسجيل دخول**: أي شخص يملك رابط الموقع يستطيع عرض وتعديل البيانات، حسب ما تم الاتفاق عليه.
- **التحديثات اللحظية**: مفعّلة تلقائيًا عبر Supabase Realtime — أي تعديل من أي عضو يظهر فورًا عند البقية دون الحاجة لتحديث الصفحة.
- **تقرير PDF**: يُصدَّر مباشرة من المتصفح (لا يحتاج خادم إضافي)، ويشمل قائمة المشاريع والمهام مع الرسوم البيانية.
- إذا احتجتِ لاحقًا تعديل تصميم أو إضافة ميزة (إشعارات، تعليقات، سجل نشاط)، الكود مقسّم بمكوّنات منفصلة في `src/components` يسهل التوسع منها.
